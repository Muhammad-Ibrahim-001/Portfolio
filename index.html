Selected Projects

x86 Bare-Metal Bootloader & Kernel Bootstrap

x86 Assembly (NASM) C QEMU Protected Mode BIOS Internals GDT / IDT

Implemented a two-stage bootloader from scratch in x86 NASM assembly with zero OS dependencies. Stage 1 (MBR) initializes the stack and loads Stage 2 from disk via BIOS INT 13h; Stage 2 configures the Global Descriptor Table (GDT), manipulates the CR0 protection bit, and transitions the CPU from 16-bit real mode to 32-bit protected mode. Bootstrapped a minimal C kernel with stack setup, BSS zeroing, execution handoff to kernel_main(), VGA text-mode output, E820 memory map parsing via BIOS INT 15h, and Interrupt Descriptor Table (IDT) initialization.

Network Intrusion Detection System

Python Scikit-learn XGBoost Pandas NumPy EDA & Feature Eng

Developed an end-to-end machine learning pipeline on the UNSW-NB15 dataset (257,000 records, 45 features) for binary and multi-class network intrusion detection. Engineered 64 features via label encoding and one-hot encoding; trained Random Forest (87.29% accuracy) and XGBoost (87.33% accuracy, 0.99 attack recall) classifiers across binary and multi-class scenarios. Extended pipeline to multi-class classification across 9 attack categories including DoS, Exploits, and Backdoors, achieving 82.72% accuracy with detailed precision, recall, and F1-score evaluation reports.
