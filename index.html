2026 Systems / Assembly

x86 Bare-Metal Bootloader & Kernel Bootstrap

Implemented a two-stage bootloader from scratch in x86 NASM assembly with zero OS dependencies. Stage 1 (MBR) initializes the stack and loads Stage 2 from disk via BIOS INT 13h; Stage 2 configures the Global Descriptor Table (GDT), manipulates the CR0 protection bit, and transitions the CPU from 16-bit real mode to 32-bit protected mode. Bootstrapped a minimal C kernel with stack setup, BSS zeroing, execution handoff, VGA text-mode output, E820 memory map parsing via BIOS INT 15h, and Interrupt Descriptor Table (IDT) initialization.
